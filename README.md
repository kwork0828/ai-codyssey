# ai-codyssey — B1-1 상담일지 자동화 챗봇 과제

> **상태: 완료 (Codyssey B1-1 과제, 문서 저장소)**
> 이전에 이 README에 있던 대화 로그 전문은 [03_대화로그/README.md](03_대화로그/README.md)에 그대로 있습니다.

취업 상담 메모를 회사 양식(4항목)의 **상담일지로 자동 변환하는 챗봇**을 설계한 과제입니다.
모델 3종을 비교해 채택 모델을 정하고, 시스템 프롬프트와 퓨샷 예시를 설계한 뒤, 실제 대화로 환각 방지와 맥락 유지를 검증했습니다.

## 핵심 판단

- 상담일지 자동화의 핵심은 **없는 내용을 지어내지 않는 것**이므로, 동점 모델 중 환각 방지 점수가 높은 Claude를 채택
- 실제 상담 데이터는 이름·학번을 마스킹한 뒤 사용
